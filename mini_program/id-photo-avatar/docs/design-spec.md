# AI证件照头像制作小程序 - 设计规范

## 设计概述

基于微信原生小程序开发的AI证件照头像制作工具，采用专业商务风格设计，重点突出简洁、高效、可靠的用户体验。

### 设计风格

- **主风格：** 专业商务
- **设计语言：** 现代、简洁、高效
- **目标用户：** 需要证件照和头像制作的各类用户

### 底部导航 - 居中突出样式

- 高度：120rpx（含安全区域）
- 选中项：图标置于渐变背景圆形容器中，向上突出
- 未选中项：简洁图标+文字
- 选中颜色：#234e52
- 未选中颜色：#a0aec0

## 功能页面设计

### 证件照制作页面

1. **上传区域** - 大区域，支持拍照/相册选择
2. **预览区域** - 实时显示处理效果
3. **操作选项**
   - 底色切换：白色/蓝色/红色
   - 尺寸选择：一寸/二寸
4. **操作按钮** - 开始处理/保存

### AI头像生成页面

1. **模式切换** - 图片生成/文字生成
2. **上传/输入区域**
3. **风格选择** - 卡通/油画/素描/3D/像素/水彩
4. **生成按钮**

### 历史记录页面

- 卡片式展示历史作品
- 支持重新保存、删除
- 时间倒序排列

### 个人中心页面

- 用户信息展示
- 会员推广入口
- 隐私政策/服务协议
- 基础设置

## 交互规范

### 点击反馈

- 按钮按下：透明度变为 0.8
- 卡片按下：轻微缩放效果
- 导航切换：平滑过渡

### 加载状态

- 全局加载：全屏loading
- 局部加载：区域内loading动画
- 处理动画：进度提示

### 动画规范

- 过渡时间：300ms
- 缓动函数：ease-out
- 避免过于花哨的动画，保持专业感

## 字体规范

| 类型 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 大标题 | 36rpx | 600 | 页面标题 |
| 中标题 | 32rpx | 500 | 模块标题 |
| 正文 | 28rpx | 400 | 主要内容 |
| 辅助文字 | 24rpx | 400 | 次要信息 |
| 小字 | 20rpx | 400 | 提示文字 |

## 适配规范

- 基础单位：rpx
- 设计稿基准：750rpx = 屏幕宽度
- 安全区域：适配全面屏底部安全区域
- 适配范围：iPhone SE ~ iPad

## 技术实现要点

1. **微信原生小程序** - 使用 WXML + WXSS + JavaScript
2. **无后端架构** - 本地Storage存储
3. **第三方API** - 接入AI处理服务
4. **广告组件** - 微信原生广告组件
